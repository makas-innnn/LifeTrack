# LifeTrack

**LifeTrack** — это твой личный помощник для контроля привычек, заметок и финансов.  
Приложение работает полностью офлайн, хранит все данные только на твоём устройстве и не требует регистрации.

## 🛠️ Возможности

- **Привычки:** добавляй полезные (или вредные) привычки, отмечай выполнение и следи за серией дней (🔥 Streak).
- **Заметки:** быстро записывай мысли, списки дел или идеи. Дата создания сохраняется автоматически.
- **Финансы:** 
  - Учёт расходов и доходов.
  - Категории (Еда, Транспорт, Вредное, Зарплата и др.).
  - Фильтры по датам (Все / Сегодня / Неделя / Месяц).
  - Показ топ-категории трат.
- **Кастомизация:** 4 темы на выбор (Тёмная, Светлая, Фиолетовая, Лесная).
- **Безопасность:** все данные хранятся в локальном файле `lifetrack_data.json`, никакие данные не уходят в интернет.

## 📱 Сборка APK

Приложение собирается автоматически через **GitHub Actions**.  
Чтобы получить APK:
1. Перейди во вкладку **Actions**.
2. Выбери последнюю успешную сборку.
3. Скачай `flet-apk.zip` из раздела **Artifacts**.
